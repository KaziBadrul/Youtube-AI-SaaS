## Scope and frozen boundaries

Solo creator: topic or approved pasted script → editable fully narrated image-based educational video. Core English landscape 16:9, primary 3–10 minutes, 1920×1080 MP4/30 fps; shorter scripts preserved, >10-minute adaptation/translation requires approval. Three presets: Minimal Illustration (default), Storybook, Documentary Illustration. Default five-minute topic, captions/motion ON, music OFF. Core lifecycle, entitlement-aware Research, pasted checking, consent-controlled factual corrections, scene planning, generated/replaced/versioned images, built-in narration, reviewed mappings, captions/style/correction, timing, optional gentle motion/library music, scene corrections/reorder/delete/restore, retry/resume/cancel and protected exports are included. Original input stays separate from current approved script.

Core invitations do not include Director/timeline, reusable Style Studio/custom styles, extensive model controls, recurring characters, video/custom-audio uploads, arbitrary new/duplicate scenes, project duplicate/archive, public signup/external auth, YouTube publishing/derived short-form, billing/commercial credit formulas/prices, advanced templates/marketplace, font uploads or custom animations. Standalone 9:16 and Emphasis Text are follow-up Alpha milestones. Topic/Custom/Expert Suggestions are accepted distinct product/entitlement decisions with shipping unassigned, not added to the invitation gate.

One codebase: Django web/API with focused browser enhancement, separate controlled Python production worker, coordinated maintenance on a persistent host. No durable HTTP execution, separate frontend/render service, broker or managed database requirement. SQLite local WAL/foreign keys/durable settings, short transactional CAS/exclusion, integer financial units; no transaction spans network/media work. PostgreSQL is a fallback for demonstrated topology/contention/reliability need. Host-local private immutable media is referenced by opaque logical keys; binary bytes are outside SQLite.

Typed User/Project/Original Input/Script/Scene/artifact and version records preserve stable IDs and exact provenance, alongside Research Result/Factual Warning, Job/Operation/Attempt, Render/Final Export, allowance/authorization/reservation/liability and deletion authority. Valid, selected, compatible/outdated, review needed and last attempt outcome are independent. Deterministic invalidation/restoration rules have one home in ARTIFACT_MODEL.md; no universal arbitrary JSON domain or generic workflow engine.

One active production request globally, relational queue and supervised fenced worker. Exact starting input/configuration signatures govern selection; late valid results are history/accounted once. Relevant queued edits refresh authorization. Asset generation permits edits; final render locks all content. Lease expiry, timeout, cancellation intent or missing heartbeat is not cessation. Unknown paid outcomes preserve liability and prevent blind retry/replacement execution. Paid success/save failure recovers existing bytes before new generation.

Narration uses **B initial / B corrections**: coherent deterministic multi-scene provider segments; corrected words regenerate the whole affected segment, preserving other sources/history. Scene mappings drive visual/caption timing without cutting continuous narration. Each next visual begins at the next mapped narration start; speech end/visual interval/extraction range stay distinct. Group sizing remains bounded configuration, not 500 words/3,000 bytes. Intentional scoped restoration/reorder/delete must independently validate ranges/coverage/joins, preserve unrelated selections and block uncertainty; no C1 correction fallback is selected.

Different-word restoration requires explicit compound text/audio/compatible timing/caption approval and script update. Same-word/different-delivery restoration discloses effective configuration and adopts it only for the scoped selection, not project defaults/siblings. Restoration does not consume generation allowance. Accepted minor meaning-preserving spoken variations remain version-bound approval records separate from script/ASR/provenance; material errors/uncertain required mappings block publishable selection, never crash the app or silently trigger paid repair.

Narrow bounded adapters: text/planning, application-controlled Tavily Basic research, selected image `gemini-3.1-flash-lite-image`, selected TTS `gemini-3.8-flash-lite-tts`. Normal text model remains a capability decision; the `gemini-3.5-flash-lite` reference is not silently adopted. Research: bounded tool-free planner → validated queries → app-owned searches → bounded sources → tool-free synthesis/check. No model-controlled searches, extra generated-script factual pass, mandatory humanization or paid TTS-preparation stage. Provider caps/usage/attempt identities and cost certainty are explicit; hidden SDK retries must be disabled/bounded/surfaced.

Render pins immutable ordered artifacts/settings/source hashes and contract version; validate required compatibility and acquire lock transactionally at execution. Controlled child group termination/escalation confirms cessation before unlock. Full output validation exceeds exit status/`-shortest`: decode/playability, 1080p/30fps, full narration, scene coverage/order/no blank gaps, readable enabled captions. HarfBuzz/FreeType + Pillow shaped PNG captions + FFmpeg overlays is the supported local rendering approach. Previous successful exports survive failure/cancel/edit; retries reuse assets.

Django identity/sessions, operator-provisioned private invitations, server ownership/entitlement on all project/artifact/media/write/job/render/export paths (including ranges). No public media filesystem routes/client plan authority. Image replacement is the current upload scope; staging/decoding/resource/type validation precedes immutable registration. Server-controlled argv/path resolution, never shell-concatenated user input.

Storage cap before invitations accounts for versions, retained deleted content, exports and staging/scratch reservations. Overflow blocks creation, not silent deletion. Project deletion needs confirmation, hides immediately and cancels never-started queued work atomically; active/uncertain execution requires cancel and confirmed stop first. Recovery lasts **7 days**; purge active content then backup copies on next daily cycle, **≤24 additional hours**, independent of new-backup success. Independent deletion authority/current head prevents old snapshot resurrection. Active projects remain until announced Alpha end, followed by **14-day download window**. Necessary non-content finance/audit can remain.

Daily encrypted off-machine backup, **≤24h catastrophic-loss objective**, verified restore/key recovery/purge before invitations. Restore pauses private access/paid execution until deletion authority and financial/unknown execution state are reconciled. Heavy maintenance is serialized with production; size-proportional in-memory archive behavior requires bounded memory preflight/compatible bounded implementation, not an unbounded scalability claim.
