# Design Motivation

These references are visual and structural inspiration for specific parts of the product.

They are NOT templates to copy literally. Extract the relevant design principles from each reference and combine them into a coherent original design system.

## Product References

- `products/dashboard` - Reference for the dashboard's overall structure, layout, hierarchy, and information organization.
- `products/details-button` - Reference for how a button/control that reveals additional detailed information should appear and behave.
- `products/video-editor` - Primary structural reference for the video/scene editor.
- `products/landing-page-1` - Reference for the overall landing page composition and visual direction.
- `products/button` - Reference for primary/secondary button styling.
- `products/audio-editor` - Reference for the interface used to inspect and edit TTS narration/audio.

## Typography References

- `typography/typography-1` - Reference for heading typography.
- `typography/typography-2` - Reference for subheadings, labels, and normal body text.

## Color References

- `colors/palette-dark` - Preferred direction for the dark-mode color system.
- `colors/palette-light` - Preferred direction for the light-mode color system.

## Interpretation Rules

- Do not copy any referenced product literally.
- Do not assume that liking one element means I want the entire referenced product's design language.
- Use each reference primarily for the purpose stated above.
- Resolve the references into one coherent product identity rather than creating a collage of unrelated styles.
- If references conflict materially, ask me instead of arbitrarily choosing one.
- Avoid generic AI SaaS aesthetics.
- The product should feel like a polished creative production tool while remaining approachable to creators who are not technical.

I want the product to feel:
- premium
- calm
- creative
- intentional
- fast
- approachable to non-technical creators

I do NOT want:
- generic AI SaaS
- excessive gradients
- purple AI aesthetic
- glassmorphism everywhere
- giant rounded cards
- everything inside cards
- excessive pills
- cluttered dashboards
